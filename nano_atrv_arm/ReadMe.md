# SO-ARM101

This package contains a simplified servo driver for the Lerobot SO-ARM101, with a urdf that extends the base robot and a demo ikpy node for positioning the arm using inverse kinematics.

Resources:

- https://github.com/TheRobotStudio/SO-ARM100

- https://huggingface.co/docs/lerobot/so101

- https://github.com/Kotakku/FT_SCServo_Debug_Qt
